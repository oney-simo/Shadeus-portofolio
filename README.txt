SHADEUS MATINDE PORTFOLIO

Files:
- index.html  : page structure and portfolio content
- style.css   : dark theme, responsive layout, scroll transitions
- script.js   : mobile navigation, reveal-on-scroll, active navigation
- assets/profile.jpg : supplied profile image

To preview:
1. Extract the ZIP.
2. Keep the assets folder beside index.html.
3. Open index.html in a browser. For best local development, use VS Code + Live Server.

Before publishing:
- Replace hello@yourdomain.com in index.html with your real email.
- Add real GitHub/LinkedIn links when you are ready.
- Review project statuses and wording so they accurately reflect what you have built.
